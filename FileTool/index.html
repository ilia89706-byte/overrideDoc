    fileTool

    fileTool:getDir(dirType) --> string

    dirType может быть либо sandbox(папка проекта на диске, генерируется автоматически, используйте для сохранений вашей игры), project(папка проекта где находится main.lua), и temponary. Метод возвращает путь с концом \. Все ресурсы игры берутся непосредственно из project 

    sandbox = fileTool:getDir("sandbox")
fileTool:write(sandbox .. "myFile", "hii")

    fileTool:write(filePath, content)

    Метод записывает content в filePath, при отсутствии файла он создаётся автоматически. 

    fileTool:write("test.txt","hii")

    fileTool:read(filePath) --> string

    Метод автоматически открывает->читает->закрывает файл и возвращает вам прочитанное значение. 

    fileTool:read("conf.lua") --> {windowWidth = ...

    fileTool:exists(filePath) --> boolean

    Проверяет существует ли файл. 

    if fileTool:exists("myFile") then
print("myFile exists!")
else
print("myFile not exists")
end

    fileTool:delete(filePath)

    Метод удаляет файл. 

    fileTool:delete("myFile")

    fileTool:createDir(path)

    Метод создаёт папку/дерево папок по пути. 

    fileTool:createDir("myFolder")
--===--
fileTool:createDir("myFolder2/myFolder3")

    fileTool:deleteRecursive(path)

    Метод рекурсивно удаляет папку и всё содержимое. 

    fileTool:deleteRecursive("myFolder")

    fileTool:list(path) --> table

    Метод возвращает все элементы в папке. 

    for k,v in pairs(fileTool:list("myFolder")) do
print(k,v)
end

    fileTool:isDirectory(filePath) --> boolean

    Метод проверяет является ли объект по пути папкой. 

    if fileTool:isDirectory("myFolder") then
print("folder")
else
print("file")
end

    fileTool:getFileSize(filePath) --> number

    Метод возвращает размер файла. 

    print(fileTool:getFileSize("myFile"))

    fileTool:getMetadata(path) --> table

    Метод возвращает таблицу метаданных объекта. 

    print(fileTool:getMetadata("myFile"))
--===--
print(fileTool:getMetadata("myFolder"))

    fileTool:copy(source,target)

    Метод копирует объект из одного места в другое. 

    fileTool:copy("folder/myFile","folder2/myFile")

    fileTool:move(source,target)

    Метод перемещает объект из одного места в другое. 

    fileTool:move("folder/myFile","folder2/myFile")

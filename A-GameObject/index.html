    Класс GameObject

    Графические объекты — это основная структурная единица, из которой состоит ваша игра. Все визуальные сущности в Override имеют общего предка GameObject.

    Любые объекты, созданные через фабрику display:... (прямоугольники, круги, спрайты, ноды), наследуют свойства и методы, описанные ниже. Вы можете применять их к любому объекту без исключений.

    Внимание

    Все методы объекта вызываются строго через знак двоеточия :, а не через точку .. Объекты, переданные в среду Lua из Java, являются userdata, и синтаксис : автоматически передает ссылку на сам объект (self) в качестве первого аргумента.

    Свойства объекта

    Все свойства считываются и изменяются через точку .:

    Свойство Тип данных Описание
    x number Позиция объекта по оси X относительно родительского контейнера или центра экрана.
    y number Позиция объекта по оси Y относительно родительского контейнера или центра экрана.
    width number Ширина объекта в пикселях.
    height number Высота объекта в пикселях.
    angle number Собственное вращение объекта, указывается в градусах.
    scale number Масштаб объекта (float). 1.0 — исходный размер, 0.5 — уменьшение вдвое.
    anchorX number Точка привязки (якорь) по оси X. 0.0 — левый край, 0.5 — центр, 1.0 — правый край.
    anchorY number Точка привязки (якорь) по оси Y. 0.0 — верхний край, 0.5 — центр, 1.0 — нижний край.
    anchorAngle number Смещение центра вращения объекта, указывается в градусах.
    data table Нативная Lua-таблица для безопасной записи любых кастомных полей игрока/ИИ.
    layer int Слой отображения (Z-индекс). Чем выше число, тем позже отрисуется объект (будет поверх остальных).
    color table Текущий цвет в формате таблицы {r = 255, g = 255, b = 255, a = 255}.
    isVisible boolean Видимость объекта на экране (true/false).
    mirroredX boolean Включает зеркальное отражение объекта по горизонтали.
    mirroredY boolean Включает зеркальное отражение объекта по вертикали.
    name string Имя объекта, используемое для последующего поиска по дереву нод.
    tag string Дополнительный тег. Внимание: свойство является устаревшим и будет удалено в будущих версиях.

    Методы управления и жизненного цикла

    GameObject:remove

    GameObject:remove()
    Полностью уничтожает объект, удаляет его из игрового мира, освобождает память, а также рекурсивно удаляет всех его дочерних наследников.

    • Пример использования: 
      local box = display:rect(0, 0, 100, 100)
box:remove()

    GameObject:clear

    GameObject:clear()
    Рекурсивно уничтожает всех дочерних наследников текущего объекта, но оставляет сам объект-родитель нетронутым.

    • Пример использования: 
      -- Очистить весь слой игрового интерфейса
uiLayer:clear()

    Трансформация в пространстве

    GameObject:getWorldX

    GameObject:getWorldX() --> number
    Возвращает глобальную координату X объекта на экране (в системе координат игрового мира), полностью игнорируя смещения его родителей.

    GameObject:getWorldY

    GameObject:getWorldY() --> number
    Возвращает глобальную координату Y объекта на экране, полностью игнорируя смещения его родителей.

    GameObject:getWorldAngle

    GameObject:getWorldAngle() --> number
    Возвращает абсолютный угол поворота объекта относительно игрового мира.

    GameObject:lookAt

    GameObject:lookAt(x, y)
    Автоматически рассчитывает направление и поворачивает объект так, чтобы он смотрел на указанную точку с глобальными координатами (x, y).

    • Пример использования: 
      -- Заставить турель повернуться лицом к игроку в цикле update
turret:lookAt(player.x, player.y)

    Иерархия и работа с поддеревьями (Ноды)

    GameObject:insert

    GameObject:insert(childGameObject)
    Вставляет один объект внутрь другого. Объект, переданный в качестве аргумента, становится дочерним (child).

    Поведение вложенности

    Трансформации родителя (изменение x, y, scale, angle, isVisible) автоматически и каскадно применяются ко всем вложенным объектам. Это позволяет использовать пустые объекты типа node для группировки целых слоев игры.

    • Пример использования: 
      local mainGroup = display:node()
local enemy = display:rect(0, 0, 50, 50)
mainGroup:insert(enemy)

mainGroup.x = 200     -- Сместится и нода, и прямоугольник внутри неё
mainGroup:remove()    -- Будет удалена и нода, и вложенный враг

    GameObject:find

    GameObject:find(nameOrTag) --> GameObject or false
    Производит глубокий рекурсивный поиск объекта по его имени (.name) или тегу среди своих дочерних наследников. Если объект не найден, метод вернёт false.

    • Пример использования: 
      local target = gameMap:find("player_spawn_point")
if target then
    print("Точка спавна успешно найдена!")
end

    Сортировка слоев рендеринга

    GameObject:toFront

    GameObject:toFront()
    Перемещает объект на максимально высокий слой отображения среди элементов текущего контейнера, заставляя его визуализироваться поверх остальных объектов.

    GameObject:toBack

    GameObject:toBack()
    Сдвигает объект на максимально глубокий отрицательный слой, заставляя его отображаться позади всех остальных элементов контейнера.

    Цвет и визуализация

    GameObject:setColor

    GameObject:setColor(r, g, b, [a])
GameObject:setColor(hexString)
    Динамически изменяет цвет и прозрачность объекта. Метод является перегруженным и поддерживает два формата ввода.

    • Варианты вызова:
      • r, g, b, a (numbers) — компоненты цвета от 0 до 255. Альфа-канал a является необязательным (по умолчанию 255).
      • hexString (string) — строка цвета в формате HEX (например, "#ff5733" или сокращенный "#ff57").
    • Пример использования: 
      -- Установка цвета через RGBA
hero:setColor(0, 200, 255, 150)

-- Установка цвета через HEX строку
hero:setColor("#ff5733")

    Управление событиями (Events)

    GameObject:on

    GameObject:on(eventName, callback)
    Подписывает объект на системное или кастомное игровое событие и регистрирует функцию-слушатель (callback).

    • Пример использования: 
      local button = display:rect(100, 100, 200, 50)
button:on("touch", function(event)
    print("Объект зафиксировал нажатие на экран!")
end)

    GameObject:off

    GameObject:off(eventName)
    Полностью отписывает объект от указанного события, удаляя зарегистрированного слушателя.

    • Пример использования: 
      button:off("touch")

    Примечание к Alpha-версии

    Поскольку фреймворк Override находится в стадии активной разработки, в текущей альфа-версии доступна только часть запланированного функционала. API может незначительно изменяться в обновлениях по мере тестирования стабильности методов в различных игровых условиях.

# GameObject/Text
Текст.
Свойства:
```lua
local a = display:text("myText",0,0,"myFont.ttf",5)
a.x = 0 --позиция x
a.y = 0 --позиция y
a.text = "myText" --отображаемый текст
a.fontSpacing = 5 --отступ между буквами
a.aligment = "center" --привязка текста, может быть center,right,left
--== Остальные свойства унаследованы от GameObject --==
```

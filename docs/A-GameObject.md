# GameObject
Графические объекты - это основная еденица из которой будет состоять ваша игра, все объекты имеют общего предка `GameObject`. Все объекты созданные через `display:...` наследуются от него, это значит что все нижеописанные методы можно использовать на любом объекте.

## GameObject
Свойства: 
```lua
local a = display:node()
a.x = 0 --позиция x относительно центра экрана
a.y = 0 --позиция y относительно центра экрана
a.width = 0 --ширина объекта
a.height = 0 --высота объекта
a.angle = 0 --вращение объекта в градусах
a.scale = 1 --размер объекта, указывается в float, 1.0 - оригинальный размер, 0.5 - половина от размера
a.anchorX = 0.5 --якорь по оси x, 1-смещение центра объекта вправо, 0-смещение влево
a.anchorY = 0.5 --якорь по оси y, 1-смещение центра объекта вверх, 0-смещение вниз
a.anchorAngle = 0.0 --смещение во вращении, указывается в градусах

a.data = {} --луа таблица для записи кастомных свойств объекта

a.layer = 1 --слой отображения объекта, чем выше слой тем выше приоритет рендеринга, указывается в int
a.color = {r = 255,g = 255,b = 255,a = 255} --цвет объекта
a.isVisible = true --видимость объекта
a.mirroredX = false --отзеркаливание по оси x
a.mirroredY = false --отзеркаливание по оси y

a.name = "" --свойство для поиска среди объектов если это необходмо
a.tag = "" --аналог свойства выше, его добавление спорно и он скоро будет удалён
```

Методы: 
`ВНИМАНИЕ:все методы объекта вызываются строго через знак ":" а не через ".", обусловлено тем что объекты переданные в lua не являются полноценными объектами этой среды.`
## GameObject:remove()
Метод полностью удаляющий объект а так же его детей.
```lua
local a = display:rect(0,0,100,100)
a:remove()
```

## GameObject:insert(GameObject)
Метод для "вставки" одного объекта в другой, после этого действия объект переданный аргументом становится наследником объекта которым был вызван метод. Данный метод очень полезен для группировки объектов, вы можете создать объект типа `node` и складывать туда к примеру интерфейс вашей игры для управления целым слоем.
```lua
local a = display:node()
local b = display:rect(0,0,100,100)
a:insert(b)

a.x = 200 --позиция прямоугольника тоже изменится
a:remove() --прямоугольник удалён вместе с нодой так как он является наследником
```
Вы можете собирать сложные деревья вложенностей, параметры по типу `isVisible` автоматически повлияют на дочерних объектов.

## GameObject:find(string nameOrTag) -> GameObject
Метод ищет объект среди наследников объекта от которого был вызван метод, при неудаче вернёт `false`.
```lua
local buffer = a:find("name")
if buffer then
buffer:remove()
end
```

## GameObject:clear()
Метод для полной очистки детей, он рекурсивно проходит по наследникам объекта(метод выше) и удаляет их оставляя только родителя.
```lua
a:clear()
```

## GameObject:on(string name,function callback)
Подпись на событие(со списком доступных событий для этого метода можно ознакомиться во вкладке Events), вы можете подписать объект на кастомное событие/событие движка и установить слушатель для конкретного объекта.
```lua
local a = display:rect(0,0,100,100)
a:on("touch",function(e)
print("great")
end)
```

## GameObject:off(string name)
Отписка объекта от события(метод выше).
```lua
a:off("touch")
```

## GameObject:lookAt(num x,num y)
Метод заставляющий объект смотреть в точку x,y.
```lua
a:lookAt(300,300)
```

## GameObject:toFront()
Метод устанавливает максимально возможный слой объекта заставляя его рендерится над другими.
```lua
a:toFront()
```

## GameObject:toBack()
Метод устанавливает максимально отрицательный слой объекта заставляя его рендерится под другими.
```lua
a:toBack()
```

# Примечание
Этот модуль может изменяться по мере обновлений, в alpha версии недоступно больше половины функционала так как фреймворк находится в активной разработке и методы нужно проверять на работоспособность в разных комбинациях и условиях.
